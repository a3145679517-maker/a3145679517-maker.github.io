## v0.1.1 修复记录

- 一级页面不再叠加粗略裁切的整图，改为在热点本身做高亮，避免悬停时出现错位叠影。
- 图片容器保持与原始插画相同的宽高比，热点与显示内容使用一致坐标。
- 旧版浏览器本地内容中的照片地址会迁移到随网页发布的素材文件。

## 这次需求怎么变了

最初计划在用户提供的雪山河流插画上保留原图，并让雪山区域可以点击，进入一个二级页面。现在调整为两个二级页面：一个看雪山实景，一个看雪山与河流交会的实景。两个页面都能从一级页面进入，也能从另一个二级页面进入。

本 Demo 继续以用户提供的插画作为一级页面原素材。雪山和河流区域作为可点击入口；进入二级页面后展示对应的实景照片和内容。原插画仍作为底图保留，不用新图替换整张插画。

## 页面与入口

```text
一级：原始雪山河流插画
  ├─ 点击雪山区域 → 二级 A：雪山
  └─ 点击河流区域 → 二级 B：雪山与河流交会

二级 A：雪山
  └─ 可进入二级 B

二级 B：雪山与河流交会
  └─ 可进入二级 A
```

- **PAGE-001**：一级页面使用用户提供的原始插画；保留其整体画面作为底图。
- **PAGE-002**：一级页面包含两个可点击区域，分别对应雪山和河流。具体点击范围在页面预览时再确认。
- **PAGE-003**：雪山点击入口打开“雪山”二级页面，使用用户选定的第三张照片作为主素材。
- **PAGE-004**：河流点击入口打开“雪山与河流交会”二级页面，第一张和第二张照片都在此页展示。
- **PAGE-005**：两个二级页面均提供前往另一个二级页面的入口，也提供返回一级页面的入口。
- **PAGE-006**：每个页面有清楚的标题和导航；刷新页面或直接打开页面链接时，仍能进入对应页面。
- **PAGE-007**：桌面和手机浏览器均可完成一级页面与两个二级页面之间的浏览。
- **PAGE-008**：二级页面按纵向滚动浏览；每个内容段落先放一张图片，图片下方放一段文字。
- **PAGE-009**：雪山页使用第三张照片；雪山与河流交会页展示第一、第二张照片。内容不预填个人经历或观点。

## 编辑方式

- **EDIT-001**：访客页面提供编辑模式，可编辑页面标题、段落标题、正文和素材说明。
- **EDIT-002**：编辑模式可以替换图片、添加或移除“图片＋文字”段落；新增段落按纵向顺序继续排列。
- **EDIT-003**：本 Demo 的编辑改动保存到当前浏览器，并支持 JSON 导入和导出，便于试用和备份。此次 Demo 不包含跨设备同步或在线后台。

## 交互与后续扩展

- **NAV-001**：点击一级页面的雪山或河流入口后，进入对应的二级页面。
- **NAV-002**：从任一二级页面可切换到另一个二级页面，也可返回一级页面。
- **NAV-003**：页面导航不依赖鼠标悬停；触屏设备也能打开入口。
- **EXT-001**：页面层级和入口关系以可维护的数据或清楚的页面配置记录，后续可增加三级页面或更多主题页面。
- **EXT-002**：每个素材保留来源、作者、许可和用途信息，方便之后替换或复用。

## 交付内容

1. 一个任何人都能通过链接打开的网页，包含一级页面和两个二级页面。
2. 一个可供同事复刻流程的 Skill，包含适用于统一 AI 工作台／WorkBuddy 的使用说明。
3. README，说明如何准备原图、确认照片、制作点击区域、添加页面、预览和发布。
4. 页面素材及来源记录，确保后续维护时能找到照片出处和许可信息。

## 验收方式

1. 一级页面展示原始插画，雪山和河流是两个独立入口。
2. 点击雪山进入雪山页面；点击河流进入雪山与河流交会页面。
3. 河流页纵向展示两组“图片＋文字”；雪山页至少有一组“图片＋文字”。
4. 两个二级页面彼此可以切换，并能返回一级页面。
5. 编辑模式可以改文字和图片、增删段落；刷新后当前浏览器仍保留改动，也可导出和导入 JSON。
6. 页面可通过公开链接访问，手机和电脑都能操作。
7. 页面所用照片及其来源、作者和许可信息可查。
8. Skill 和 README 足以让同事按照步骤准备素材、增加页面并预览结果。
