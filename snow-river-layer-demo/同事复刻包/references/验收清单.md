# 图片分层网页验收清单

## 原图与热点

- [ ] 原图保留，网页副本没有覆盖原文件。
- [ ] 页面容器和图片比例匹配；裁切后热点位置按实际显示范围计算。
- [ ] 每个热点跳转正确，鼠标和键盘都能操作。
- [ ] 悬停或聚焦时没有重复影像、错位色块或遮挡文字。

## 页面与素材

- [ ] 一级页能打开所有指定二级页面；互链和返回入口正常。
- [ ] 二级页按“图片后接文字”排列；增删改符合需求。
- [ ] 刷新或直接访问链接后，页面仍正确显示。
- [ ] 图片加载成功，来源和许可可查看。
- [ ] 未提供的文字标为待补充；不补写虚构内容。
- [ ] 已说明编辑数据保存位置及公开更新方式。

## 交付

- [ ] 桌面和手机预览完成。
- [ ] README 包含预览、素材替换、版本和发布说明。
- [ ] 公开链接可访问，现有网站其他页面没有被覆盖。
