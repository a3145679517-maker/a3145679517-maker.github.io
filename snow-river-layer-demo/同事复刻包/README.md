# 图片分层网页 Skill｜同事复刻包

适用于使用 AI 工作台搭建图片分层网页的同事。把 Skill 加入工作台后，可让 AI 按相同方法处理原图热点、嵌套页面、图文素材和发布检查。

## 文件

- SKILL.md：复用型工作说明。
- references/验收清单.md：交付前的检查表。

## 添加到 AI 工作台

如果工作台支持 Skills：

1. 解压本文件包。
2. 将“同事复刻包”文件夹上传或复制到 Skills/技能目录。
3. 新建任务，说明“请使用图片分层与嵌套页面 Skill”，并提供原图、点击区域、每个区域要打开的内容。
4. 若工作台支持自动调用 Skill，开启自动调用；否则每次任务开头提到该 Skill。

如果工作台没有 Skills 功能，把 SKILL.md 内容放进项目 AI 工作说明或作为任务附件。不同工作台的入口名称可能不一样。

## 给 AI 的需求示例

我提供了一张原始插画。请保留原图，在雪山和河流上分别设置可点击区域。雪山进入实景详情页，河流进入另一个详情页。每个详情页纵向排列图片和文字，支持后续添加段落。请先做网页让我预览，再补充素材来源、操作说明和版本记录。公开发布前检查手机显示、热点位置和图片加载。

## 使用时准备

- 原始图片。
- 点击区域和页面主题；位置还不确定时可以在预览中确认。
- 详情页文字、照片、链接。没准备的文字标为“待补充”。
- 是否需要公开链接，以及已有的网站或仓库地址。
- 编辑方式：改源码、网页内编辑，或由维护者统一更新。

网页内编辑不一定会同步给所有访客。请说明数据保存位置和公开更新方式。
