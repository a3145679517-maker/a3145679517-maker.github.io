# 图片分层与嵌套页面

用户要在原始图片上设置可点击区域、打开二级或更深页面，或要求复刻这类图片分层网页时使用本 Skill。

## 目标

保留用户提供的原图，通过清楚、准确的点击区域进入关联页面。详情页按用户需要展示照片、文字、链接或后续层级。网页需要便于理解和维护。

## 工作方法

1. 确认原图、点击区域对应内容、页面跳转关系和交付形式。缺失的信息标成具体待补充项，不编造正文或素材说明。
2. 保留原始文件。需要压缩、裁切或转格式时，另存网页使用的副本。
3. 检查原图宽高比。图片、热点坐标和视觉反馈使用同一坐标系：容器尽量匹配原图宽高比；若使用 object-fit 裁切，按实际裁切范围计算热点位置。
4. 热点应覆盖对应画面区域，鼠标点击和键盘聚焦都能触发。交互时可用轻微色彩、边框或阴影标出区域。
5. 不要叠加整张原图，再用粗略多边形裁切冒充精确抠图；重复图层容易产生错位块。需要浮起效果时使用经过检查的真实透明蒙版，否则就在原图上高亮热点。
6. 页面层级、互链和返回入口按用户确认的结构实现。纵向图文页以“图片、对应文字”为一个可增删段落，允许编辑的内容要一眼看出。
7. 说明编辑结果保存在哪里。浏览器本地保存只影响当前设备；若用户需要所有访客看到更新，需要服务端内容管理或重新发布流程。
8. 公开图片记录来源和许可。关键图片优先随站点部署，避免依赖会拦截外链的服务。
9. 保留已有网站和仓库内容，只在指定目录新增或更新页面。用户要求公开链接时，沿用指定或已授权的托管方式并检查最终链接。

## 验收

发布或交付前检查：

- 原始图片没有被覆盖，桌面和手机布局完整。
- 每个点击区域进入正确页面，互链和返回入口正常。
- 详情页图片加载成功，图文顺序正确；编辑、新增、删除和重新打开后的保存行为符合说明。
- 鼠标悬停、键盘聚焦没有错位的重复图层，热点位置与主题一致。
- 直接访问各层级链接或刷新后仍显示对应页面。
- 公开图片有来源和许可说明。
- README 写明预览、维护、素材替换、版本更新和发布步骤。

发现问题先修复，再重复受影响的验收项。未确认的内容标成待补充，不用虚构内容填满。
