# 雪山河流图片分层 Demo

一个可浏览的静态网页，用来验证“原始插画上的局部入口 → 实景照片详情页”的交互。

## 页面结构

- 首页保留原始雪山河流插画。雪山和河流区域分别可以点击，也可以使用首页下方的页面入口。
- **雪山**页面展示路易斯湖雪山照片。
- **雪山与河流交会**页面沿纵向排列两组“图片 + 文字”。两张照片分别展示冬季山谷河流和九寨沟雪林溪流。
- 两个详情页之间可以互相切换，也都能返回首页。

首页的点击区域使用裁切蒙版叠在原图上；悬停或键盘聚焦时，对应区域会轻微抬起并显示入口名称。区域边界属于 Demo 初稿，可根据预览意见再调整。

## 编辑页面内容

打开任一详情页，点击右上角 **编辑内容**：

1. 点击标题或文字直接编辑。
2. 点击 **换图片**，输入网络图片地址，或取消后选择本地图片。
3. 点击 **新增图片和文字**，添加一组新的内容；需要时可以移除某一段。
4. 点击右上角向下箭头，导出 JSON 备份；向上箭头可导入之前导出的 JSON。
5. 点击 **完成编辑** 后，改动会保存在当前浏览器。

这份 Demo 没有在线内容管理后台。编辑结果保存在当前设备的浏览器里，不会自动同步给其他访客。要更新公开页面，可以把确认后的文字和图片交给维护者，再随网站版本一起发布。上传图片建议先压缩到 1 MB 左右；浏览器存储空间有限。

## 本地预览

这是 buildless 静态页面，直接用本地静态服务器打开 `dist/index.html` 即可。网页源码在 `dist/`，静态图片放在 `dist/assets/`。
