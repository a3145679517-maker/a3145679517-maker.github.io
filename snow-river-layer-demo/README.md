# 雪山河流图片分层 Demo

一个静态网页，用来验证“在原始插画上点击局部区域，进入图片与文字详情页”的做法。

## 页面结构

- 首页保留用户提供的原始雪山河流插画。雪山和河流区域可点击，也可通过首页入口打开。
- “雪山”页面展示路易斯湖与雪山照片。
- “雪山与河流交会”页面按纵向排列两组“图片 + 文字”。
- 两个详情页可互相切换，也都能返回首页。

原图比例与网页画框保持一致。鼠标悬停或键盘聚焦时，直接在对应区域显示轻微高亮，避免复制整张图片造成错位叠影。

## 编辑页面内容

打开任一详情页，点击右上角“编辑内容”：

1. 点击标题或文字可直接编辑。
2. 点击“换图片”，输入网络图片地址，或选择本地图片。
3. 点击“新增图片和文字”添加段落；需要时可移除段落。
4. 使用右上角按钮导出或导入 JSON 备份。
5. 点击“完成编辑”后，内容保存在当前浏览器。

编辑结果仅保存在当前浏览器。其他访客不会自动看到这些修改；确认要公开的内容后，需要维护者把它更新到网页并重新发布。上传图片建议先压缩到 1 MB 左右，浏览器存储空间有限。

## 本地预览

这是 buildless 静态页面。用本地静态服务器打开 dist/index.html。网页源文件在 dist/，图片在 dist/assets/。

## 图片来源与许可

- 首页插画：用户提供，作为本 Demo 的原始底图；网页使用压缩副本，不覆盖原始文件。
- 雪山照片：Rschroeder1985，Wikimedia Commons，CC0。
- 冬季河流照片：Dreamy Pixel，Wikimedia Commons，CC BY 4.0。
- 九寨沟雪林溪流照片：Gear$Head，Wikimedia Commons，CC BY-SA 3.0。

详情页展示图片来源。替换照片时，同步更新 dist/app.js 的来源和许可信息。
